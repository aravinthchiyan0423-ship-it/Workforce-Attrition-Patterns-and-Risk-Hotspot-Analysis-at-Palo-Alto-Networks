# Workforce-Attrition-Patterns-and-Risk-Hotspot-Analysis-at-Palo-Alto-Networks
Data-driven analysis of employee attrition at Palo Alto Networks — identifies department, role, tenure, and workload risk hotspots. Includes EDA, KPI dashboard (Streamlit), and a full research paper. Key finding: OverTime + Frequent Travel employees exit at 41.86%, the highest-risk segment in the org.
